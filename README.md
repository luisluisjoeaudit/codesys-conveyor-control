# codesys-conveyor-control
Automation project developed by a student featuring a simulated conveyor control system in CODESYS, using ladder logic, sensors, timers, counters, fault handling, and HMI visualization.

# CODESYS Conveyer Control System

## Overview
The purpose of this project is to develop a simulated conveyer belt capable of transporting boxed goods between locations. The project will allow the boxes to stop at specific points to be analyzed by sensors while demonstrating how control logic can be utilized to manage a conveyer belts' operations.

At the moment, there will be no hardware which will be used. Instead, the project will be programmed through Ladder Logic in CODESYS. By doing so, I will be able to advance my skills in troubleshooting and PLC programming by creating a fully functional conveyer belt system. 

## Objectives 
Right now, my main goal is to get myself a solid foundation in PLC programming and logic development, specifically fault handling and HMI vizualization. My project should ensure that the conveyer belt can manage normal operations, process conditions, and detect faults, which will aid me in developing and testing control logic. 

## Software 
CODESYS version: V3.5 SP22 Patch 2 
Program Language: Ladder Logic 
Simulation: CODESYS Control Win V3 x64
